### 3. Security Enhancement ✅

#### Per-Bootcamp Google Sheets Configuration

**Before**:
- Single Google Sheets credentials in .env
- All bootcamps shared one sheet
- Sensitive keys exposed in environment
- Hard to rotate credentials

**After**:
- Each bootcamp has own credentials in Sanity
- Separate Google Sheet per bootcamp
- No sensitive keys in .env files
- Easy credential management
- Better security & scalability

#### Implementation
- ✅ Updated Sanity schema with googleSheets fields
- ✅ Updated API to fetch from Sanity
- ✅ Updated types for TypeScript support
